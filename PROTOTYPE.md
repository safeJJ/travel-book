# Prototype 01

This branch contains the first interactive UX prototype for Travel Book.

## Included flow

1. Create a trip with a name and destination.
2. Show the successful creation state and invite link.
3. Simulate a guest opening the invite.
4. Let the guest enter a nickname and choose an avatar.
5. Enter a contextual mobile-first trip home screen.

## Not included yet

- Authentication
- Persistence or database integration
- Real invite tokens
- Date selection
- Itinerary editing
- Shared fund transactions
- Memory scrapbook uploads

The goal of this prototype is to validate clarity, tone, hierarchy, and the balance between a simple interface and playful scrapbook details before implementing the production architecture.
