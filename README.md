# Travel Book

Mobile-first collaborative trip planner presented as an interactive travel scrapbook.

## Product direction

- Plan trips together with friends
- Vote on destinations and travel dates
- Build daily itineraries
- Track shared expenses and responsibilities
- Save trip memories as a scrapbook
- Prioritize mobile interactions, performance, and accessibility

## Planned stack

- Next.js + TypeScript
- Tailwind CSS
- Motion for React
- Supabase (Auth, Postgres, Realtime, Storage)
- Mapbox or Google Maps
- Vercel

Development work should be submitted through pull requests rather than committed directly to `main`.
